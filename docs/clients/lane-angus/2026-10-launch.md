## Flags for the client

1. **Free dinner guide:** the bundles page says it's "for first-time customers", but Ads 1 and

   on the page.
2. **"8G PROTEIN. 45 CALORIES." (Jerky ad 4):** confirm these are per-serving figures on

4. **"No subscription" (Bundles ad 2):** make sure the checkout offers no subscription option,
   and that the box products aren't set up as subscription products in the store. The second
   point may also relate to the tracking issue (source E below).

## Tracking issue: `Subscribe` fires when someone adds to cart

**Why deleting rules didn't help:** Manage Events only lists rules created with the Event Setup
Tool. The other ways an event reaches the pixel never show up there: Meta's automatic event
detection, code on a single page or in GTM, and server-side partner events. An empty rules
list tells us the event comes from one of those.

**Most likely cause (not yet confirmed, because we couldn't open Events Manager from here):**
Meta's **automatic events** setting in the dataset settings. Meta guesses standard events from
button text and page content, and "BUILD MY 6-PACK" on a box offer is an easy thing to misread
as a subscription.

**A 5-minute check that confirms which cause it is:** in Test Events, click the `Subscribe` row
and read:

- **Exact name:** if it says `SubscribedButtonClick`, it's Meta's automatic button-click metadata.
  It isn't a conversion and doesn't affect optimisation.
- **Received from + setup method:**
  - Browser + *Automatic events* → dataset **Settings → automatic events**. Turn it off, or turn
    off just the inferred `Subscribe` event.
  - Browser + *Code* → a script is sending it. Check per-page header injection (Page settings →
    Advanced) on `/shop-beef` and the landing pages, Code blocks, GTM, and the landing-page
    tool's own tracking settings.
  - Server / *Squarespace* → it's the Conversions API integration. Check whether the products
    are set up as subscription products.

The full decision table is in
`.claude/skills/meta-advertiser/references/pixel-troubleshooting.md`.

InitiateCheckout → Purchase, with no `Subscribe`.
